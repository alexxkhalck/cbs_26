
# Порушення 1NF
| id | name      | phones  |
| -- | --------- | ------- |
| 1  | Олександр | +38097111,  +38097222 |

# Виправлення 1NF

Створюємо окрему таблицю.

### users

| id | name      |
| -- | --------- |
| 1  | Олександр |

### phones

| id | user_id | phone |
| -- | ------- | ----- |
| 1  | 1       | +38097111   |
| 2  | 1       | +38097222   |

# Повторювані групи даних

Ще один приклад порушення 1NF:

| id | product1 | product2 | product3   |
| -- | -------- | -------- | ---------- |
| 1  | Ноутбук  | Мишка    | Клавіатура |

### orders

| id |user_id |
| -- |---|
| 1  | 1 |

### order_items

| id | order_id | product    |
| -- | -------- | ---------- |
| 1  | 1        | Ноутбук    |
| 2  | 1        | Мишка      |
| 3  | 1        | Клавіатура |

# Друга нормальна форма (2NF)

Для переходу до 2NF таблиця повинна:

1. Відповідати 1NF.
2. Усі неключові поля повинні залежати від повного первинного ключа.


| order_id | product_id | product_name |
| -------- | ---------- | ------------ |
| 1        | 10         | Ноутбук      |
| 1        | 11         | Мишка        |

# Усунення порушення 2NF

Розділимо таблицю.

### products

| id | name    |
| -- | ------- |
| 10 | Ноутбук | 
| 11 | Мишка   |

### order_items

| order_id | product_id |
| -------- | ---------- |
| 1        | 10         |
| 1        | 11         |

Тепер залежності коректні.

# Третя нормальна форма (3NF)

Для переходу до 3NF таблиця повинна:

* відповідати 2NF;
* не містити транзитивних залежностей.

# Що таке транзитивна залежність

Приклад:

| user_id | city | postal_code |
| ------- | ---- | ----------- |
| 1       | Kyiv | 01001       |

Поле: `postal_code`
визначається через: `city`

# Усунення порушення 3NF

Створимо окрему таблицю.

### cities

| id | city | postal_code |
| -- | ---- | ----------- |
| 1  | Kyiv | 01001       |

### users

| user_id | city_id |
| -- | ------- |
| 1  | 1       |


# Аномалія вставки

| Alex       | 1             |

# Аномалія оновлення

Приклад:

| user_name | phone |
| --------- | ----- |

| Олександр | 111   |

# Аномалія видалення

Приклад:

| user_name | <=(order) |
| --------- | ----- |
| Ірина     | 1000  |
