# Заняття 32. SELECT, JOIN і підзапити

## Мета заняття

На попередніх заняттях ми навчилися створювати таблиці, додавати та змінювати дані, а також виконувати прості запити за допомогою `SELECT`.

У реальних базах даних інформація майже завжди зберігається у декількох пов'язаних таблицях. Наприклад:

* користувачі зберігаються в таблиці `users`;
* замовлення — в таблиці `orders`;
* товари — в таблиці `products`.

Для отримання повної інформації необхідно об'єднувати дані з кількох таблиць. Для цього використовується оператор **JOIN**.

На цьому занятті ми розглянемо:

* принцип роботи JOIN;
* основні типи JOIN;
* сортування результатів через `ORDER BY`;
* обмеження кількості рядків через `LIMIT`;
* використання підзапитів.

# Навіщо потрібен JOIN

Розглянемо дві таблиці.

### Таблиця users

| id | name      |
| -- | --------- |
| 1  | Олександр |
| 2  | Ірина     |
| 3  | Петро     |

### Таблиця orders

| id | user_id | amount |
| -- | ------- | ------ |
| 1  | 1       | 500    |
| 2  | 1       | 1200   |
| 3  | 2       | 300    |

У таблиці `orders` немає імен користувачів.

Замість цього використовується поле:

```sql
user_id
```

яке посилається на:

```sql
users.id
```

Щоб побачити ім'я користувача разом із його замовленнями, потрібно об'єднати таблиці.

# INNER JOIN

Найпоширеніший тип JOIN.

Повертає лише ті рядки, для яких знайдено відповідність в обох таблицях.

```sql
SELECT
    users.name,
    orders.amount
FROM users
INNER JOIN orders
    ON users.id = orders.user_id;
```

Результат:

| name      | amount |
| --------- | ------ |
| Олександр | 500    |
| Олександр | 1200   |
| Ірина     | 300    |

Петро не потрапив до результату, тому що у нього немає замовлень.

# Синтаксис JOIN

Загальний вигляд:

```sql
SELECT колонка1, колонка2
FROM таблиця1
JOIN таблиця2
    ON умова_об'єднання;
```

Приклад:

```sql
ON users.id = orders.user_id
```

Тут SQL порівнює значення полів і знаходить пов'язані записи.

# Псевдоніми таблиць

Довгі назви таблиць незручно писати багато разів.

Тому використовують псевдоніми.

```sql
SELECT
    u.name,
    o.amount
FROM users AS u
JOIN orders AS o
    ON u.id = o.user_id;
```

Ключове слово `AS` можна не писати:

```sql
FROM users u
JOIN orders o
```

Такий запис часто використовується в реальних проєктах.

# LEFT JOIN

Повертає всі рядки з лівої таблиці.

Якщо відповідності немає, SQL підставить `NULL`.

```sql
SELECT
    users.name,
    orders.amount
FROM users
LEFT JOIN orders
    ON users.id = orders.user_id;
```

Результат:

| name      | amount |
| --------- | ------ |
| Олександр | 500    |
| Олександр | 1200   |
| Ірина     | 300    |
| Петро     | NULL   |

Тепер Петро присутній у вибірці.

# RIGHT JOIN

Працює аналогічно до LEFT JOIN, але зберігає всі рядки правої таблиці.

```sql
SELECT
    users.name,
    orders.amount
FROM users
RIGHT JOIN orders
    ON users.id = orders.user_id;
```

У PostgreSQL використовується рідко.

У більшості випадків можна просто поміняти таблиці місцями та використати `LEFT JOIN`.

# FULL JOIN

Повертає всі записи з обох таблиць.

Якщо відповідності немає — заповнює значення `NULL`.

```sql
SELECT
    users.name,
    orders.amount
FROM users
FULL JOIN orders
    ON users.id = orders.user_id;
```

Використовується для пошуку невідповідностей між таблицями.

# Візуалізація типів JOIN

### INNER JOIN

Тільки спільна частина.

```text
users ∩ orders
```

### LEFT JOIN

Усі записи зліва + спільні.

```text
users + перетин
```

### RIGHT JOIN

Усі записи справа + спільні.

```text
orders + перетин
```

### FULL JOIN

Обидві таблиці повністю.

```text
users ∪ orders
```

# JOIN трьох таблиць

Об'єднувати можна не лише дві таблиці.

Наприклад:

### users

```text
Користувачі
```

### orders

```text
Замовлення
```

### products

```text
Товари
```

Запит:

```sql
SELECT
    u.name,
    p.name,
    o.amount
FROM orders o
JOIN users u
    ON o.user_id = u.id
JOIN products p
    ON o.product_id = p.id;
```

Так можна отримати всю необхідну інформацію одним запитом.

# ORDER BY

За замовчуванням порядок рядків не гарантується.

Для сортування використовується:

```sql
ORDER BY
```

Приклад:

```sql
SELECT *
FROM users
ORDER BY name;
```

Результат буде відсортований за алфавітом.

# Сортування за спаданням

За замовчуванням використовується:

```sql
ASC
```

(від меншого до більшого).

Для сортування у зворотному порядку:

```sql
SELECT *
FROM orders
ORDER BY amount DESC;
```

Результат:

```text
1200
500
300
```

# Сортування за декількома колонками

```sql
SELECT *
FROM users
ORDER BY
    city,
    name;
```

Спочатку сортування відбудеться за містом.

У межах одного міста — за ім'ям.

# LIMIT

Часто необхідно отримати лише кілька рядків.

Для цього використовується:

```sql
LIMIT
```

Приклад:

```sql
SELECT *
FROM users
LIMIT 5;
```

Повернуться тільки перші п'ять рядків.

# ORDER BY + LIMIT

Дуже популярна комбінація.

Наприклад, знайти найбільше замовлення.

```sql
SELECT *
FROM orders
ORDER BY amount DESC
LIMIT 1;
```

Результат:

```text
Замовлення на 1200
```

# Що таке підзапит

Підзапит — це SQL-запит усередині іншого SQL-запиту.

Приклад:

```sql
SELECT *
FROM users
WHERE id = (
    SELECT user_id
    FROM orders
    WHERE amount = 1200
);
```

Спочатку виконається внутрішній запит.

Потім його результат буде використано зовнішнім запитом.

# Підзапит у WHERE

Знайдемо користувачів, які мають хоча б одне замовлення.

```sql
SELECT *
FROM users
WHERE id IN (
    SELECT user_id
    FROM orders
);
```

Внутрішній запит поверне список:

```text
1, 2
```

Після цього SQL знайде відповідних користувачів.

# Підзапит з агрегатною функцією

Знайдемо замовлення з максимальною сумою.

```sql
SELECT *
FROM orders
WHERE amount = (
    SELECT MAX(amount)
    FROM orders
);
```

Спочатку обчислюється:

```sql
MAX(amount)
```

Потім виконується пошук записів із цим значенням.

# Підзапит у FROM

Результат підзапиту можна використовувати як тимчасову таблицю.

```sql
SELECT *
FROM (
    SELECT *
    FROM orders
    WHERE amount > 500
) AS expensive_orders;
```

Такі конструкції часто використовуються у складних звітах.

# Коли використовувати JOIN, а коли підзапит

### JOIN підходить коли:

* потрібно показати дані з кількох таблиць;
* необхідно отримати колонки з різних таблиць;
* потрібно побудувати звіт.

### Підзапит підходить коли:

* потрібно знайти проміжне значення;
* необхідно виконати фільтрацію;
* використовується агрегатна функція (`MAX`, `AVG`, `COUNT`).

У сучасних проєктах JOIN використовується значно частіше.

# Типові помилки

### Забули умову JOIN

Неправильно:

```sql
SELECT *
FROM users
JOIN orders;
```

Помилка або декартовий добуток.

### Переплутали поля

Неправильно:

```sql
ON users.id = orders.id
```

Правильно:

```sql
ON users.id = orders.user_id
```

### LIMIT без ORDER BY

```sql
SELECT *
FROM orders
LIMIT 10;
```

SQL поверне довільні перші 10 рядків.

Якщо потрібні найбільші чи найновіші записи — обов'язково використовуйте `ORDER BY`.
