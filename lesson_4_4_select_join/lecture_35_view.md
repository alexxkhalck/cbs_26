### Заняття 35. Агрегація, групування та представлення даних. Аналіз даних у SQL. Розширені SQL-запити

У реальних проєктах розробники та аналітики використовують агрегатні функції, групування, віконні функції та представлення (`VIEW`), які дозволяють отримувати складну статистику без написання великої кількості коду.

# Вкладені запити

Вкладений запит (Subquery) — це SQL-запит, який виконується всередині іншого запиту.

Загальний вигляд:

```sql
SELECT *
FROM table_name
WHERE column_name = (
    SELECT value
    FROM another_table
);
```

Спочатку виконується внутрішній запит, а його результат використовується зовнішнім запитом.

# Приклад вкладеного запиту

Знайдемо замовлення з максимальною сумою.

```sql
SELECT *
FROM orders
WHERE amount = (
    SELECT MAX(amount)
    FROM orders
);
```

Спочатку SQL обчислить:

```sql
SELECT MAX(amount)
FROM orders;
```

Наприклад, результатом буде:

```text
2500
```

Потім буде знайдено всі замовлення на суму 2500.

# Підзапити та оператор IN

Знайдемо всіх користувачів, які робили замовлення.

```sql
SELECT *
FROM users
WHERE id IN (
    SELECT user_id
    FROM orders
);
```

Підзапит повертає список ідентифікаторів, а оператор `IN` перевіряє наявність значення в цьому списку.

# Вбудовані функції SQL

SQL містить велику кількість готових функцій.

Найпоширеніші:

| Функція | Призначення       |
| ------- | ----------------- |
| COUNT() | Підрахунок рядків |
| SUM()   | Сума значень      |
| AVG()   | Середнє значення  |
| MIN()   | Мінімум           |
| MAX()   | Максимум          |

# COUNT

Підрахунок кількості записів.

```sql
SELECT COUNT(*)
FROM users;
```

Результат:

```text
125
```

Запит поверне кількість рядків у таблиці.

# SUM та AVG

Обчислення суми та середнього значення.

```sql
SELECT
    SUM(amount),
    AVG(amount)
FROM orders;
```

Результат:

| sum   | avg    |
| ----- | ------ |
| 10000 | 833.33 |

# MIN та MAX

Пошук мінімального та максимального значення.

```sql
SELECT
    MIN(amount),
    MAX(amount)
FROM orders;
```

Результат:

| min | max  |
| --- | ---- |
| 100 | 2500 |

# Навіщо потрібен GROUP BY

Агрегатні функції працюють над усією таблицею.

Часто потрібно отримати статистику по групах.

Наприклад:

* кількість замовлень кожного користувача;
* середню зарплату по відділах;
* суму продажів по містах.

Для цього використовується:

```sql
GROUP BY
```

# GROUP BY

Порахуємо кількість замовлень кожного користувача.

```sql
SELECT
    user_id,
    COUNT(*)
FROM orders
GROUP BY user_id;
```

Результат:

| user_id | count |
| ------- | ----- |
| 1       | 5     |
| 2       | 3     |
| 3       | 8     |

# GROUP BY з декількома колонками

Можна групувати за кількома полями.

```sql
SELECT
    city,
    status,
    COUNT(*)
FROM users
GROUP BY city, status;
```

Спочатку буде сформовано групи за містом, а потім за статусом.

# HAVING

Після групування часто потрібно залишити лише певні групи.

Для цього використовується:

```sql
HAVING
```

# Різниця між WHERE і HAVING

### WHERE

Фільтрує рядки до групування.

```sql
SELECT *
FROM orders
WHERE amount > 500;
```

### HAVING

Фільтрує групи після групування.

```sql
SELECT
    user_id,
    COUNT(*)
FROM orders
GROUP BY user_id
HAVING COUNT(*) > 5;
```

# Приклад HAVING

Знайдемо користувачів, які зробили більше трьох замовлень.

```sql
SELECT
    user_id,
    COUNT(*)
FROM orders
GROUP BY user_id
HAVING COUNT(*) > 3;
```

До результату потраплять лише відповідні групи.

# DISTINCT

Іноді потрібно отримати лише унікальні значення.

Для цього використовується:

```sql
DISTINCT
```

# Приклад DISTINCT

Отримаємо список міст без повторень.

```sql
SELECT DISTINCT city
FROM users;
```

Результат:

```text
Kyiv
Lviv
Dnipro
Odesa
```

Кожне місто буде показане лише один раз.

# DISTINCT ON у PostgreSQL

`DISTINCT ON` є особливістю PostgreSQL.

Він дозволяє залишити лише один рядок із групи.

Наприклад, останнє замовлення кожного користувача.

```sql
SELECT DISTINCT ON (user_id)
    user_id,
    amount,
    created_at
FROM orders
ORDER BY user_id, created_at DESC;
```

# Навіщо потрібні віконні функції

Звичайні агрегатні функції згортають групу в один рядок.

Віконні функції дозволяють:

* виконувати обчислення по групі;
* зберігати всі рядки результату;
* будувати рейтинги;
* рахувати накопичувальні підсумки.

# Перша віконна функція

```sql
SELECT
    user_id,
    amount,
    AVG(amount) OVER()
FROM orders;
```

Результат:

| user_id | amount | avg |
| ------- | ------ | --- |
| 1       | 500    | 850 |
| 2       | 1200   | 850 |
| 3       | 850    | 850 |

Середнє значення буде показано для кожного рядка.

# OVER()

Ключове слово:

```sql
OVER()
```

перетворює звичайну агрегатну функцію на віконну.

Наприклад:

```sql
COUNT(*) OVER()
SUM(amount) OVER()
AVG(amount) OVER()
```

# PARTITION BY

Дозволяє розбити записи на групи всередині вікна.

```sql
SELECT
    user_id,
    amount,
    AVG(amount) OVER(
        PARTITION BY user_id
    )
FROM orders;
```

Тепер середнє буде обчислюватися окремо для кожного користувача.

# ROW_NUMBER

Присвоює номер кожному рядку.

```sql
SELECT
    user_id,
    amount,
    ROW_NUMBER() OVER(
        ORDER BY amount DESC
    )
FROM orders;
```

Результат:

| amount | row_number |
| ------ | ---------- |
| 2500   | 1          |
| 1800   | 2          |
| 1200   | 3          |

# RANK

Формує рейтинг із врахуванням однакових значень.

```sql
SELECT
    amount,
    RANK() OVER(
        ORDER BY amount DESC
    )
FROM orders;
```

Якщо два записи мають однакове значення, вони отримають однаковий ранг.

# Накопичувальна сума

Віконні функції дозволяють обчислювати підсумки.

```sql
SELECT
    created_at,
    amount,
    SUM(amount) OVER(
        ORDER BY created_at
    )
FROM orders;
```

Такий підхід часто використовується для фінансової аналітики.

# Що таке VIEW

VIEW (представлення) — це віртуальна таблиця.

Вона не зберігає дані окремо.

Замість цього PostgreSQL зберігає SQL-запит.

# Створення VIEW

Приклад:

```sql
CREATE VIEW active_users AS
SELECT *
FROM users
WHERE is_active = TRUE;
```

Тепер можна працювати з представленням як зі звичайною таблицею.

# Використання VIEW

Після створення:

```sql
SELECT *
FROM active_users;
```

PostgreSQL автоматично виконає збережений запит.

# Переваги VIEW

* спрощення складних запитів;
* приховування деталей реалізації;
* повторне використання SQL-коду;
* зручне створення звітів;
* додатковий рівень безпеки.

# Типові помилки

### Забули GROUP BY

Неправильно:

```sql
SELECT
    user_id,
    COUNT(*)
FROM orders;
```

Правильно:

```sql
SELECT
    user_id,
    COUNT(*)
FROM orders
GROUP BY user_id;
```

# Типові помилки

### Використання агрегатної функції в WHERE

Неправильно:

```sql
WHERE COUNT(*) > 5
```

Правильно:

```sql
HAVING COUNT(*) > 5
```

# Типові помилки

### Відсутність ORDER BY у DISTINCT ON

Неправильно:

```sql
SELECT DISTINCT ON (user_id)
    *
FROM orders;
```

Правильно:

```sql
SELECT DISTINCT ON (user_id)
    *
FROM orders
ORDER BY user_id, created_at DESC;
```
